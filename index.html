ПАТРУЛИ

СЛУЖЕБНЫЙ РАЗДЕЛ // ДОСТУП ПОДТВЕРЖДЁН
01Общие положения

1.1.

Патруль — это МП, в котором участвуют от 3 человек (включая проводящего). Один человек — это сам проводящий, остальные — участники.

1.2.

Участники обязаны выполнять приказы проводящего без обсуждений.

1.3.

Патруль длится минимум 30 минут, максимум — 1 час 30 минут.

02Типы патрулей

2.1.

Свободные — проводящий разрешает идти в любой из секторов комплекса.

2.2.

По секторам — проводящий распределяет участников по секторам. Один может быть поставлен в А-сектор, другого — в любое место из Б-сектора.

03Мега-рейд

3.1.

Во время патруля может начаться мега-рейд. В этот момент проводящий начинает командовать бойцами для отбития рейда, и его приказы становятся приоритетными.
